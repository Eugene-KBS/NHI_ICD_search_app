# 醫療碼搜尋（健保碼 + ICD-10-CM）

給整形外科醫師用的手機小工具：打幾個字，就找到健保支付碼與 ICD-10-CM 診斷碼。裝到 iPhone 主畫面後，沒有網路也能用。

## 怎麼用
1. 上方兩個分頁：`健保碼`、`ICD-10-CM`。直接打代碼、中文、英文或縮寫（例如 `STSG`、`清創`、`62032`、`keloid`、`rt index fx`）。打錯字會自動修正，畫面上會寫「已修正」。
2. 一句話含兩個診斷（例如 `right hand crushing injury with tendon rupture`）會自動拆成 ① ② 兩段，各自列出結果。
3. **點一下卡片 = 加入「本次病人」清單**（再點一次移除）。ICD 卡片點下去同時會複製代碼。
4. 健保碼卡片若有「規範 ▾」，按下去可看健保署官方原文。
5. 畫面下方出現 `本次病人　診斷 2・手術 3　›`，按進去：
   - 診斷依你點的順序，第一個是主診斷（可按 ↑ 調整）；手術依點數由高到低，並顯示合計點數。
   - `複製全部`：把整份清單複製成文字，貼到病歷即可。
   - `完成並清空`：清空清單，同時讓 app 記住這次的搭配。
   - `直接清空（不記錄）`：清空但不學習。

## 它會學你的習慣
你常用的碼會排前面；下次選了某個手術，常搭配的診斷會出現在「常一起用」。搜尋框空白時會顯示「最近使用」「最常用」。所有紀錄只存在這支手機裡，不會上傳。

備份／換手機：病人清單頁最下方 `匯出使用紀錄` 存成檔案，新手機用 `匯入使用紀錄` 讀回即可。

## 資料來源與每月更新
- 健保碼：健保署開放資料（支付標準），每月 1 日由 GitHub 自動更新 `nhi.json`；畫面最下方有資料日期。
- ICD-10-CM：2023 年版（`icd.txt`），索引詞來自美國 CDC。
- 手動更新：到 GitHub 專案的 Actions 頁面，選 `update-nhi`，按 `Run workflow`，等約一分鐘即完成。手機重開 app 一兩次就會拿到新資料。

## 開發者檢查
`node tests/ui_smoke.js` 會用真的 Chrome 跑一遍畫面測試（需要已安裝 Playwright）。
